# 三、R0：TTA 数值有效性改进

## 3.1 现有问题

TASK011A 已经发现：

Flip TTA 相对分歧：

T = |D_native - D_flip| / (|D_native| + ε)

当 Native 深度接近零时，分母过小，会产生极端数值。

部分 VIPER 样本的分歧达到数千万级别。

此外，已有缓存包含 `tta_valid`，但 TASK011A 的融合计算没有真正将它作为像素级有效性门控。

因此需要重新设计 TTA 数值处理。

## 3.2 检查现有缓存

检查以下字段：

- native_depth
- flip_depth
- native_confidence
- flip_confidence
- flip_relative_disagreement
- flip_log_disagreement
- tta_valid
- native_bin_entropy
- native_bin_variance
- native_bin_max_probability
- native_effective_bins

明确：

1. 每个字段的来源和实际含义。
2. 深度输出的单位、范围和有效条件。
3. Flip 前后的坐标对齐关系。
4. tta_valid 的生成逻辑。
5. 零值、负值、NaN、Inf 的具体分布。

不得修改已有 NPZ 原始缓存。

## 3.3 建立三个有效性标记

分别定义：

Native Validity：

Native 深度是否有限且大于有效深度下限。

Flip Validity：

Flip 深度是否有限且大于有效深度下限。

Pair Validity：

Native 和 Flip 均有效，同时满足原始 `tta_valid` 条件。

严格区分：

- 正常深度。
- 零深度。
- 近零深度。
- 负深度。
- 非有限输出。
- TTA 无效输出。

无效像素不能被当作零分歧，也不能被赋予高可靠性。

Native 有效而 TTA 无效时，采用 Native-only 回退。

Native 本身无效时，不允许使用该像素的深度先验。

## 3.4 比较三种分歧定义

保留原始公式作为历史对照：

Legacy Relative：

T1 = |Dn - Df| / (|Dn| + ε)

新增对称相对分歧：

T2 = |Dn - Df| / (|Dn| + |Df| + ε)

新增 Log Disagreement：

T3 = |log(Dn + ε) - log(Df + ε)|

所有分歧均在有效的 Pair Validity 像素上计算。

另外保留 Absolute Difference：

T4 = |Dn - Df|

对比不同定义的：

- 数值稳定性。
- 极端值比例。
- 分位数分布。
- 不同天气环境下的表现。
- 高误差像素识别能力。
- Risk-Coverage 表现。

注意：T2 是有界相对分歧，T3 是对数尺度分歧，两者不能直接混淆。

输出：

- TTA_VALIDITY_AUDIT.csv
- TTA_DISAGREEMENT_COMPARISON.csv
- TTA_NUMERICAL_STATISTICS.csv
- TTA_VALIDITY_VISUALIZATION/

# 四、R1：Validity-Aware Depth Reliability

## 4.1 设计目标

将深度可信度分为两个独立来源：

1. Native Confidence：模型自身对深度预测的置信信息。
2. Flip Consistency：不同输入方向下深度预测的一致性。

不将两者直接解释为正确概率。

建立统一的风险分数：

Risk ∈ [0,1]

数值越高表示相对风险越高。

可靠性分数：

Reliability = 1 - Risk

它只是用于排序和先验控制的相对评分，不是深度正确概率。

## 4.2 实现五种对照方法

A. Native Only

使用原始 Native Confidence 构建风险排序。

B. Flip Only

只在有效 Pair Validity 像素上使用 Flip Disagreement。

C. Rank Fusion

分别对 Native 风险和 Flip 风险进行百分位排名：

R_rank = 0.5 × R_native + 0.5 × R_flip

TASK011A 已经使用 0.5 权重，本任务保留它作为主要融合基线。

D. Max Fusion

R_max = max(R_native, R_flip)

用于比较保守风险识别策略。

E. Validity-Aware Fusion

在 TTA 有效像素上使用双通道融合。

在 TTA 无效、但 Native 有效的像素上回退到 Native Only。

Native 无效的像素不参与深度先验。

对每一种方法记录实际有效像素数量，禁止将无效 TTA 像素偷偷纳入融合。

## 4.3 评价指标

继续使用：

- AUROC。
- AP。
- AUSE。
- AURG。
- Spearman。
- Pearson。
- Risk-Coverage。
- Error Quantile。
- Error Bins。

错误事件阈值：

AbsRel > 0.1

AbsRel > 0.2

AbsRel > 0.5

同时增加固定风险覆盖率评价：

保留 20%、40%、60%、80% 的低风险像素，比较剩余像素的实际误差。

分析不同方法在不同覆盖率下的误差变化。

不将风险排序指标包装为概率校准结果。

## 4.4 数据划分与评价纪律

继续使用已有 MVS-Synth 缓存进行辅助分析。

保留 TASK011A 严格 GT 准入失败的历史记录。

不允许删除那7个零预测像素来制造更好的指标。

原始严格评价和零扩展诊断必须分开报告。

# 五、R2：CADP-DR 独立实验分支接入

## 5.1 核心架构

继续使用 TASK011A 的 CADP-DR 接口设计。

两个变量必须独立：

Geometry Need：

表示当前几何系统对深度先验的需求程度。

Depth Reliability：

表示当前深度先验的相对可信程度。

核心控制关系：

s(f,p) = g(f) × r(f,p)

其中：

- g(f)：帧级几何需求。
- r(f,p)：像素级深度可靠性。
- s(f,p)：最终先验控制系数。

必须保证 Geometry Need 和 Depth Reliability 不相互替代。

Geometry Need 不得直接使用 Native Confidence 代替。

Depth Reliability 不得直接使用 DROID-W 原生 U 代替。

## 5.2 实现要求

首先检查：

`CADP_DR_INTERFACE_DESIGN.md`

然后检查 DROID-W 现有深度先验的真实计算路径。

找到：

- 深度先验生成位置。
- 先验有效掩码。
- 深度先验曲率和梯度贡献。
- BA 优化中的相关参数。
- 原生不确定性 U 和 UBA 的计算路径。
- Schur Complement 和阻尼更新位置。

将 s(f,p) 接入已有深度先验贡献位置。

参考接口：

C_s = C_g + m × s × α + (1 - m × s) × η

b_s = b_g - m × s × α × (d - d_m)

以上是接口设计表达，必须先映射到当前代码中的实际变量、量纲和更新方向，不能直接照抄公式而忽略原有 Hessian/Gradient 定义。

保持：

1. 原生 U 不变。
2. 原生 UBA 不变。
3. 原有 BA 求解顺序不变。
4. 原有 Schur 求解不变。
5. 原有阻尼机制不变。
6. 原有初始化和优化迭代配置不变。

只研究深度先验贡献的可靠性控制。

## 5.3 实验配置

建立独立实验配置文件，能够切换：
