# Task 004｜评分口径与统计单位

## 评分输入

原始 RGB ID 1–487 对应 VIPER Camera ID 0–486（Camera ID=RGB ID−1）。保留原 R2 的 pose 约定、游戏单位及有效位姿判定；估计在原生 W2C 以 xyzw 输出，离线验证刚体变换并反演为 C2W。轨迹处理和 GT 都在模型之外。拒绝重复 ID、错位、非有限值、无效四元数及不匹配映射。全局对齐只在同一个完整轨迹的有效对应上拟合一次，记录覆盖、退化秩和对齐误差。GT 位移 ≤1e−6 游戏单位时，位移比未定义；估计位移也接近零时方向角未定义。报告原因。

## 主要端点 312→328

令 C2W 为 (Qᵢ,pᵢ)，d=pⱼ−pᵢ，带 GT 下标为标注量。固定 Task003 参考尺度 s_ref=19.1341794347。

| 指标 | 定义 |
| --- | --- |
| 相对位移 | 原始长度 ‖d‖、固定尺度长度 s_ref‖d‖，以及 100 × s_ref‖d‖/‖d_GT‖；单位和百分比分开。和 100% 的绝对差用于防止把过冲解释成改善。 |
| Translation RPE | ‖s_ref Qᵢᵀd−Q_GT,iᵀd_GT‖。不使用局部拟合尺度或方向。 |
| Rotation RPE | (Q_GT,iᵀQ_GT,j)ᵀ(QᵢᵀQⱼ) 的测地旋转角（度），夹紧数值舍入误差。 |
| 位移方向误差 | 每次运行用完整导出的全局对齐旋转把世界系位移旋到 GT 系，计算与 d_GT 的夹角；旋转固定复用到该运行所有阶段，另报对齐来源。全局对齐失败则方向不可用，仍可保留有效的尺度比和相对 RPE。 |

每个可比的局部 BA 记录 pre/post 两端姿态、阶段、ba_id、触发 RGB、顺序与图边。两端在同一原生快照时才计算；同时标记两端是否落入实际窗口、是否有连接观测、是否是被拒绝的临时候选。按调用对比较，不能把不同运行第 n 次 BA 当成同一状态。主时间轴对齐触发 RGB；并报告各自全局 BA 次数和同 RGB 内的顺序，不跨缺失间段插值填充。

预先报告：第一次共同 BA 的原生返回值、首次共同返回后的最低值、从首次共同返回到前端末的下降、后续峰值到前端末的回落（正、负、零均保留，单位百分点）、首次严格小于 20% 的可比事件（若从未低于阈值则标明）、前端末原生关键帧位移比。只有临时候选的结果可以描述过程，不能替代最终保留的关键帧对。

## 关键帧身份、下游与全轨迹

- 按完整 RGB ID 报告相对 E0 的关键帧交集、并集、Jaccard、数量和差异列表。固定 312/328 任一缺少真正保留的关键帧，主 K→K 终点指标标记 ENDPOINT_NOT_RETAINED 或 ENDPOINT_UNAVAILABLE。有 Filler 时，其相同 RGB 端点只在独立的导出类别下评分。共同关键帧对结果列入支持性的子集分析，注明子集选择受干预影响。
- 309→325 和 301→353 报插值、Filler 批内优化结束及最终导出；保留两个端点各自的 batch ID 与左右原生锚点。真实 keyframe 被重新插入时，分别报告临时值和导出值。跨批比较不当成同一次优化更新。
- 全轨迹：Sim(3) 与 SE(3) ATE RMSE、对齐尺度与秩、Translation/Rotation RPE（按原始 RGB ID 精确帧距 1/15/60/150，分别报同一全局 Sim(3) 缩放和平移未缩放口径，旋转不因尺度变化）、有效 RPE 对数、关键帧数、导出数、有效位姿及覆盖 487 的比例。Nominal 时间如报告，按既有评价合同标注，不声称独立采集时钟。用 Sim(3) fit 去解释绝对尺度结果时附带 SE(3) 评分。
- 生成四层结果：局部 BA 的机械结果、Final BA 与 Filler 的下游变化、最终导出及全序列质量、运行资源和完整性。不能用较小的全局 ATE 抹去局部短缩，不能只选成功序列中较好的指标。

配对差值、七个效应与缺失值处理见 [统计计划](TASK004_FACTOR_INTERACTION_PLAN.md)。筛选只报告方向与量级；确认阶段以完整独立运行、配对区组为统计单位，报告均值、中位数、SD、置信区间与缺失。像素、BA 调用或临时姿态并非独立重复。
