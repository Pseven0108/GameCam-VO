# CONTROLLED MECHANISM ISOLATION

用户已批准两个研究方案：

A. Fixed-State BA Direct D Effect
B. Fixed-Keyframe Schedule Crossover

目标：分离 Metric3D 深度正则 D 对 DROID-W 前端局部几何优化的直接影响，以及通过关键帧选择和图结构变化产生的间接影响。

## 3. EXPERIMENT A: FIXED-STATE BA D TOGGLE

### 3.1 Objective

证明或否定：

在完全相同的BA输入状态下，Metric3D深度正则D是否直接改变局部位姿优化结果。

### 3.2 Candidate checkpoints

优先检查Seed43：

- E0: D=1,W=1,U=1。
- E1: D=0,W=1,U=1。

重点候选：

E0:
- trigger RGB328
- BA550, BA551, BA552

E1:
- trigger RGB328
- BA660, BA661, BA662

必须确认：

- RGB312和RGB328均处于有效pose window。
- 两者在当前BA观测边中。
- 对应direct edge有效。
- 快照位于第一次目标BA调用之前。

如原始归档无法恢复快照，不得仅凭BA编号推测状态。

### 3.3 Paired replay

对于每个完整快照：

复制同一状态为两个分支。

Branch A:
- D=1
- W=1
- U=1

Branch B:
- D=0
- W=1
- U=1

仅改变Metric3D深度正则是否注入。

严格固定：

- 初始poses
- disparities
- intrinsics
- graph edges
- source/target indices
- correlation features
- context
- hidden state
- U
- UBA weights
- optimizer
- damping
- iteration count
- CUDA kernel
- BA调用顺序

两个分支必须使用同一份输入张量的独立副本。

禁止在一个分支运行后直接使用其更新后的状态作为另一个分支输入。

不执行keyframe accept/reject决策。

不改变图结构。

### 3.4 Measurements

记录每次BA调用：

1. pose translation increment。
2. pose rotation increment。
3. RGB312→RGB328 relative pose。
4. translation direction error。
5. fixed-scale displacement ratio。
6. reprojection residual。
7. Metric3D prior residual。
8. uncertainty weights。
9. disparity update norm。
10. pose update norm。
11. BA objective before/after。
12. gradient and normal-equation contribution when available。
13. negative disparity and clamp statistics。

直接BA结果必须来自真实BA状态。

不得使用Filler或插值位姿代替直接BA结果。

### 3.5 Interpretation

如果D=1在相同输入状态下持续产生更差的位姿更新，支持D的直接几何影响。

如果两分支单次BA差异很小，但完整前端结果差异明显，则应重点检查多轮优化累积和关键帧选择。

不得预先认定某个分支一定更好。

## 4. EXPERIMENT B: FIXED KEYFRAME SCHEDULE CROSSOVER

### 4.1 Objective

分离D与关键帧选择、图结构变化之间的影响。

### 4.2 Schedule sources

使用Seed43原始Task004B记录：

S1:
- E0
- D=1,W=1,U=1

S0:
- E1
- D=0,W=1,U=1

两组framewise keyframe decisions从RGB21开始出现差异。

必须从共同初始化结束后的main-loop起点开始重放，不能从不同的已分叉状态直接比较。

验证两组初始化状态和模型输入哈希。

### 4.3 Four-arm crossover

| Arm | D | Schedule |
|---|---:|---|
| B1 | 1 | S1 |
| B2 | 0 | S1 |
| B3 | 1 | S0 |
| B4 | 0 | S0 |

W=1,U=1固定。

### 4.4 Freeze requirements

每个Schedule必须冻结：

- accepted/rejected RGB IDs
- keyframe insertion order
- keyframe cache update
- active window
- graph edge insertion/removal
- BA call schedule
- source/target edge indices
- iteration count
- keyframe eviction policy

不能只冻结最终关键帧数量。

同一Schedule内，D=1和D=0必须使用完全相同的关键帧和图结构调度。

D允许改变BA优化输出，但不能改变外部强制调度。

Final BA、Filler、初始化及其原始处理流程保持不变。

### 4.5 Measurements

每个Arm记录：

- final keyframe IDs
- graph topology
- edge count
- 312→328 local relative pose
- 309→325
- 301→353
- Sim3 ATE
- SE3 ATE
- Translation RPE
- Rotation RPE
- Filler contribution
- Final BA contribution
- runtime and memory

直接关键帧端点缺失时标记UNAVAILABLE。

不得用Filler补齐后冒充直接关键帧BA结果。

### 4.6 Interpretation

比较：

1. D=1 vs D=0 under S1。
2. D=1 vs D=0 under S0。
3. S1 vs S0 under D=1。
4. S1 vs S0 under D=0。

报告D效应、schedule效应及D×schedule交互。

称为controlled keyframe-schedule intervention。

不得直接宣称已经获得自然因果中介效应。
