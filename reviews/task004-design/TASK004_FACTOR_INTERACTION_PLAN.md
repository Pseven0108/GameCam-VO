# Task 004｜主效应与交互的计算

## 量与时间对齐

每个已完成的新运行，对每个预先指定的运行级指标产出一个值 y。核心指标是 312→328 在前端结束、Final BA 前的固定尺度位移百分比；配套指标为 |y−100|、相对平移 RPE、Rotation RPE。首次共同 BA 后的比例、最低值、最大回落（百分点）、首次低于 20% 的事件与时序见 [指标计划](TASK004_METRIC_AND_STATISTICS_PLAN.md)。阈值用于描述，不用于删除或挑选样本。首次共同 BA 之前的 0% 不参与最低值或回落计算。对不同处理产生的自然轨迹计算总效应；同一调用前后差是诊断量，不能把不同运行的第 n 次 BA 视作同状态干预。

## 统计与缺失值

- **A 筛选**：固定顺序 E3 → E4 → E7 → E0 → E8 → E6 → E1 → E2；每组新跑一次。相同种子 43；不按中间结果改顺序。每个效应只报告方向、幅度和机制证据。不使用置信区间、p 值或显著性措辞。Task003 的 E0 单列，用新 E0 的轨迹、关键帧与耗时核对跨观测版本漂移；不得用其填缺格。
- **B 确认**：推荐三个新的完整随机化区组（同区组条件共享预先登记的种子，区组间种子不同），每组至少 3 次。启动前公布种子、组顺序和指标。每区组先计算七个效应，再跨区组报告均值、中位数、SD、配对差值及小样本区间。可对完整区组差值使用双侧 95% t 区间，给出 n 与自由度；n=3 时只描述波动和区间宽度。区间对应本序列与本协议，探索性多终点不作独立确认。筛选若用于选指标或挑条件，筛选数据不进入确认推断。
- **缺失**：GPU 故障、模型退出、日志不完整、端点某帧未成为或未保留为关键帧分别登记，照样计入运行分母。局部指标缺格时，对应完整七效应报告不可估，不以零、插值、历史值或较优组补齐；可标注有配对数据的简单效应。确认阶段逐指标列完整区组数，并报告缺失是否随处理变化。有效的全轨迹导出指标独立保留。
- **单位**：整次运行是独立实验记录；区组是配对单位。BA 事件、边、像素、相邻 RPE 对全部依赖同一运行状态，仅用于诊断。只有一个序列，不作环境总体推断。

因果表述：在限定配置下，开关干预对整个运行可估计效果。若要把效果归给某一个残差项、特定 Hessian/Schur 项或某次内迭代，还需要后续独立批准的同状态快照对照，固定图、目标、权重和初值逐项比较。本轮没有此数值证据。
