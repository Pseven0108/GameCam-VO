### **用小白方式解释**

你可以把 `Format.NHWC` 理解成一个特殊的格式标签。

它告诉 FiT3D：

- N：批次维度
- H：高度
- W：宽度
- C：通道

它虽然看起来像字符串，但实际上是一个特殊的枚举对象。

普通字符串 `"NHWC"` 和 `Format.NHWC` 不是完全相同的东西。

更重要的是，timm 内部会使用：

```
format is Format.NHWC
```

判断对象身份。

因此，不能简单把它转换成字符串保存，再恢复成普通字符串。

正确做法是：保存枚举类型身份和成员名称，恢复时重新取得原始枚举成员，并验证：

```
restored is Format.NHWC
```

这样才能保持原来的行为。

这次失败不是 ConfigDict 修复引入的，而是历史快照中一直存在、此前被 ConfigDict 问题遮挡的另一个对象类型。
