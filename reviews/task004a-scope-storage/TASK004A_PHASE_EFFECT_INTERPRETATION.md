# Task004A：阶段统计与结果判读

每个 attempt 划分为**逐调用、逐候选、逐轨迹**三种统计单元。记录臂、策略 SHA、输入清单 SHA、attempt ID、阶段和原始 RGB ID。不要用动态图的 slot 编号代替原始帧号，也不要把 CUDA BA 的一个调用与其内部求解迭代次数混计。

| 指标 | 采集与处理合同 | 如何解释缺失 |
| --- | --- | --- |
| 两阶段 BA 调用数和实际 D/W/U | 对同一 `(attempt, pid, ba_id)` 配对 `ba_before → ba_after_native → ba_after_clamp`，逐阶段计完整、未返回、未夹紧的数量。按每条真实调度回执统计 D 的选用分支与支持数、源端 W、当前更新 U，核对策略；单报原生 UBA 是否使用、U 是否更新、`motion_only` 与本次调用上下文。 | 策略预期不替代运行时实参。错标、缺行、越界阶段或实际位与策略不一致，停止后续组并保留原始日志。零次调用要带阶段覆盖状态，不能当作三开关已验证。 |
| 接受、拒绝和候选数 | 以 `trigger_rgb_id` 连接 `keyframe_candidate_inserted`、`frontend_distance`、`keyframe_decision`，确保完整运行有 487 条唯一终态决策。分别统计运动筛选拒绝、局部 BA 后拒绝、局部保留、初始化进入缓存；最终关键帧另从导出 anchor IDs 读取。 | Retained 阶段只有已接受者，拒绝计数不适用；不得把这一阶段的样本当成无偏子集。日志中断只报已观察和待判定。 |
| 原生 motion distance | 以 `frontend_distance.score` 和 `threshold` 为准，按 `trigger_rgb_id` 配对候选去留，报 n、缺失数、min/p05/p50/p95/max（排序后线性插值）、阈值和接受/拒绝分布。 | 初始化或第一层拒绝可能未计算此距离，不设为零。`motion_filter_score` 是另一层的现有观测，不能混在同一分布。接受者也可能因强制保留/连续拒绝上限而低于阈值，不从距离反推出所有分支条件。 |
| 最终关键帧清单、与 E0 交集、312/328 | 以原始 RGB ID 的最终保留集合 `K_i` 记录数量、`|K_i ∩ K_E0|`、Jaccard `|交集|/|并集|` 及各端点保留位；可另报 312/328 是否在同一次局部 BA 的可优化窗口内并被边观测。 | 直到 E0 的合法 attempt 完成前，交集为 `PENDING_E0`，不是 0。任一端点未保留时不制造关键帧位姿；为“共同 BA”另记缺失原因，不能替代最终位姿。 |
| 固定端点与直接关键帧端点 | RGB312→328 的有效最终导出位姿为全组共同评价口径；两端真关键帧的直接位姿、有效 Filler 临时位姿、导出位姿来源和共同 BA 状态分别记。沿用 Task004-A 的冻结 GT 对应和统一尺度处理。 | 即使位姿缺失或未保留也记该 arm；不插值、不以 Filler 充当 BA 快照、不只报告成功者。 |

既有数据接口：上一轮候选 `assets/candidates/preview/task003_observer.py:199–236, 246–281` 源码可区分运动过滤代理、候选结果、真实距离及底层调度位；`tools/trace_audit.py:42–62` 核对位与作用范围。日志原文可在之后独立生成逐候选分布，本轮未改解析器或 runner。原生走通仍待验证。为分阶段避免分母错用，去留和距离主要以决策前的候选为单位；决策后面板只报实际执行、覆盖及留后样本，不重复计算所有候选。

**历史 sanity check，仅作口径验证。** Task003 的原生距离 n=203，阈值 3.0，p05/p50/p95=0.834/2.311/5.309；74 个接受候选的中位数 3.985，129 个拒绝候选的中位数 1.971。该次两阶段实参位均为 111。387 次 BA 等于该次 129 个被拒候选 × 每候选 3 次决策前调用。历史 86 个最终保留关键帧与 RGB312/328 均保留，不是 E0 的数据。

**因果解释。** 固定 RGB 终点、选帧覆盖、调用分布和端点缺失一起报告；不同的关键帧/图和后续参数属于总效应的传播路径。共同关键帧是干预后的结果，交集仅作为描述，不能当作随机配对。完整八组且主指标均可评时，可以按冻结 2×2×2 合同报告三个主效应和各级交互；它们都针对 `TOTAL_FRONTEND_EFFECT`，在一个序列、一个种子上不支持跨场景或随机误差推断。失败、保留缺失、日志缺失保留为单独结果，不跳组补造因子效应。
