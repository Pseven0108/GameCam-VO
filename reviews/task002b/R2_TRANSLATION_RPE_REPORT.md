## 复算方法

- 直接使用 SHA 锁定的 `offline_evaluation.py:17–105`（`VIPER_R1_SEGMENT_METRICS_V1`）。对相机到世界位姿 `(p_i,R_i)`，计算起始相机坐标中的相对位移 `e_ij = R_i^T(p_j−p_i)`；真值同式得 `g_ij`。主指标为 `RMSE(||s·e_ij−g_ij||)`，`s` 为该模型该区段**全部有效位姿拟合一次**的 Sim(3) 尺度。不会为某个 offset、early/middle/late 或局部窗口另拟尺度。相对运动用自身起始相机坐标，不比较全局对齐后的两条端点连线。
- `unscaled` 使用 `s=1` 的原生相对位移诊断，比的是模型原生数值尺度和 GT 的位移；它不是 SE(3) ATE。SE(3) ATE 是在固定尺度下做一次整体刚体对齐后算绝对位置 RMSE。局部位移**幅度比**也不等于平移 RPE：后者含相对位移向量方向差。
- 每个运动对要求严格相隔指定 RGB ID，且中间连续、有效，同一区段内。汇总为一条源序列时，只合并区段内的平方误差和有效对数（`sqrt(sum(RMSE²×pairs)/sum(pairs))`）。环境和总组的均值按源序列等权，配对 bootstrap 按相同序列一起抽样，10,000 次、seed `20261122`、探索性百分位区间。标准差、P90/P95 均基于序列级 RMSE；没有把运动对当成独立样本。
- 四个 scope（full/early/middle/late）× 四个 offset × 92 区段 × 两模型共 2,944 行均复现。与历史 11,416 个可用 RPE 数值单元格比较，最大绝对差 `1.68523e−6`，均符合 `rtol=atol=1e−7` 的联合判定。736 个 ATE/尺度数值和 20 个 val_007 历史数值没有偏差。主表只取 `scope=full`，其他 scope 用于段内诊断。

**跨序列复发。** 使用事后描述性筛查：GT 位移至少为同区段同 offset 非零中位数的一半（非零阈值 `1e−6 game units`），且 W/GT 幅度比 `<0.5`、SLAM/GT 在 `[0.8,1.2]`；同一区段至少连续五个起始 RGB ID 满足为一处持续现象。15 帧间隔，固定 K **27/45** 条有这种现象，移除 `val_007` 后仍有 **26/44**。分组 Day 5/10、Sunset 8/10、Rain 2/7、Night 7/10、Snow 5/8。筛查对比了 30,444 对有足够 GT 位移的共同运动对，其中 2,539 对符合 W/SLAM 比值条件。五个起始 ID 可互相重叠。这个结果证明相同定义下的症状不只一条序列，尚不能证明这些序列共享同一原因；没有用该阈值重算正式排名。
