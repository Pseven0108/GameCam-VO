# Additional 2025–2026 primary-source discovery

This extends the requested candidate list. The initial broad OpenAlex discovery contained older survey hits; it is retained as a discovery log, not advertised as an exhaustive date-filtered review. The following additional sources were checked directly on2026-11-27. None of their paper benchmark numbers is treated as a result of our implementation.

| Additional source | Verified relevance / availability | Decision for this task |
|---|---|---|
| [MoVieS, official repository](https://github.com/chenguolin/MoVieS) | CVPR2026; source and pretrained reconstruction checkpoint advertised, MIT root. The README still marks dynamic segmentation/scene-flow/tracking usage as TODO, while its runnable example targets novel-view rendering with externally estimated poses. | Not a drop-in independent motion-probability provider. Do not add another reconstruction/pose pipeline merely because motion visualization is attractive. No download/benchmark claim; exact new model commit/VRAM not audited. |
| [UP-SLAM, arXiv2505.22335](https://arxiv.org/abs/2505.22335) | Submitted28May2025, ICRA2026 journal-reference field; RGB-D Gaussian SLAM with multimodal residual uncertainty. | Useful fusion reference, but its RGB-D/full-map pipeline is not a matched monocular DROID-W module. No runtime/weight/license certification here. |
| [StaDy4D / SIGMA, CVPR2026 workshop](https://openaccess.thecvf.com/content/CVPR2026W/GenRecon3d/html/Tsui_StaDy4D_Towards_Complete_4D_Static-Dynamic_Reconstruction_with_SIGMA_CVPRW_2026_paper.html) | Paired static/dynamic synthetic urban reconstruction is explicitly described by the official publication. | Promising future source of motion/depth labels for the current missing accuracy measurements. Dataset download, exact release completeness, units and pretraining overlap require a separate admission; not inferred to be solved here. No new data downloaded. |
| [FLoTS-SLAM, arXiv2610.23496](https://arxiv.org/abs/2610.23496) | Submitted16October2026; separates camera-induced flow from observed flow and uses staged optimization. Abstract states source will be released. | Motivates stage-aware geometric control. The source availability statement is not a runnable-release certificate. No official FLoTS reproduction or revival of a cancelled historical baseline is claimed. |
| [Back on Track / BA-Track, arXiv2504.14516v2](https://arxiv.org/abs/2504.14516v2) | ICCV2025 Oral; separates camera-induced motion using a learned 3D tracker, then optimizes pose/depth. | Existing admitted MDTracker is retained as an orthogonal target-replacement control. Predicted Metric3D depth and offline window usage differ from the complete author pipeline. |

For this bounded study, priority stays on independently executable GMOS-S, conference/full GeoMotion and Pi3MOS, plus geometry and separate depth/static ablations. This avoids confusing a broader survey with executed models or silently changing the baseline to a new SLAM system.
