## 四、TASK011A-R1：Native + Flip 联合融合实验

这是本次任务的核心新增实验。

### 1. 建立四组对照

| 编号   | 方法                        | 说明                    |
| ---- | ------------------------- | --------------------- |
| R1-A | Native Only               | 仅使用 Native Confidence |
| R1-B | Flip Only                 | 仅使用 Flip TTA          |
| R1-C | Native + Flip Rank Fusion | 两种信号等权秩融合             |
| R1-D | Native + Flip Max Fusion  | 两种风险信号取最大值            |

### 2. 信号预处理

先统一两个信号的风险方向：

- 深度越不可靠，风险分数越高。
- 根据原始评价脚本确认 Native Confidence 的正负方向。
- Flip TTA 差异按照实际误差风险方向处理。

对于两种信号，分别计算逐帧经验百分位秩：

`rank_native`

`rank_flip`

主实验采用等权秩融合：

`risk_fusion = 0.5 * rank_native + 0.5 * rank_flip`

R1-D 采用：

`risk_max = max(rank_native, rank_flip)`

这样能够避免 Native Confidence 和 Flip TTA 原始数值范围不同而影响简单加权。

另外可以增加0.25、0.5、0.75的融合比例敏感性分析，但不得利用最终评价集挑选最优权重并将其包装成独立测试结果。

### 3. 评价指标

所有实验使用相同有效像素 Mask 和相同评价协议。

第一类：风险排序能力

- AUROC。
- AUSE。
- Spearman。
- Average Precision。

第二类：深度误差预测能力

- 检查风险分数与实际 AbsRel 的关系。
- 分析不同风险分位区间的实际深度误差。
- 如使用误差回归映射，必须在校准序列拟合，在独立评价序列验证。
- 评价 MAE、RMSE。

第三类：概率校准能力

在具备合适独立校准样本的情况下，将风险分数映射为高误差事件概率，评价：

- Brier Score。
- NLL。
- ECE。

注意：原始 Confidence 和融合风险分数都不能直接称为正确概率。
