# TASK007A 最终评审：MP-SfM 风格 Confidence 校准准入审计

2026-11-26，Asia/Shanghai。**结论：STOPPED_AT_DATA_ADMISSION；当前不能开展 VIPER 统计校准。**

已执行真实缓存核验，依照本轮停止条件终止拟合。这个结论不是 Confidence 失效的实验结论，也不是校准成功结果。

## 直接证据

- 复用 VIPER Validation 五环境各2帧，共10帧；10份R2.1原输出及10份R2.2恢复输出文件身份通过；没有重新推理。
- 本轮逐像素完整性检查针对10份 Native Confidence：640×360网格，共 **2,304,000** 个分数全部有限；范围 **−2.5185571～6.5441108**。
- 其中 **82,079** 个分数小于0，**67,722** 个分数大于或等于1。这是输出分布检查，不是误差或概率校准。
- 重新读取 **16个本地VIPER ZIP** 的中央目录，涵盖RGB归档、重复归档和Train Camera归档；没有找到可为这些预测准入的像素深度GT。这个数量包含重复文件，不代表16个独立官方分卷。
- 另检查44个历史散落候选：19个HTML响应、6个ZIP中央目录、9个未准入的归档尾部、7个ZIP Range片段、3个只有u/v字段的光流NPZ。它们不能充当目标帧深度GT。
- 本轮读取的历史输入及候选 **74/74** 项前后SHA一致。三种审计脚本中途停止及修正原因均保留，没有覆盖原始证据。

## 停止原因

1. VIPER现有缓存只有预测及RGB/相机数据，**可准入的配对像素深度GT为0帧**。
2. 没有目标VIPER深度GT的单位、深度定义和GT有效像素掩码，不能拿预测正值掩码或TTA掩码替代。
3. 当前10帧均来自Validation，没有已冻结且无测试拟合的校准/评价设计。
4. 另一个数据集MVS-Synth的200帧GT不属于VIPER；R2.2已记录其物理单位未核实，0001也已经被观察。本轮没有重算它的误差或借用它拟合。

MP-SfM的模型适配器采用 `sigma = depth * (1 - clip(confidence, 0, 1))`；后续单先验路径另加倍率及噪声下限。
**这是源码定义，不是已经对VIPER成立的方差校准。** 67,722个分数位于原始映射的饱和区，说明只使用该原始式会产生零方差；后续原生floor不能遗漏。
不能根据饱和数量判断这些像素深度正确或错误。
