# Task 004｜观测合同与日志验收

沿用 Task003 观测点和原生 Rerun。所有组使用相同候选版本并记录补丁与策略哈希。预后快照是观察现有张量的只读副本，CPU 归约及设备读回可能改变同步时序；历史 R2、Task003 与本候选的耗时不用于算法性能比较。当前仅 CPU Mock，无本候选真实运行数据。

| 日志或产物 | 内容与核验 |
| --- | --- |
| Frame / Keyframe Event Log | 输入 RGB ID、Motion Filter、候选初始姿态来源、添加或拒绝判定、关键帧槽位与 ID；保留帧从未插入和插入后被删除两类。记录完整 487 帧的决策轨迹。 |
| Local BA | stage、同一进程的 ba_id、触发 RGB、内外循环索引、t0/t1、图边与 RGB ID 映射；调用前/原生返回/clamp 后建索引；原生有效 D/W/U、motion_only、实际送入 K、eta 抽样、lm、ep、gamma 参数、lr、weight decay 与先验输入。要求两端同事件，配对前后不拼接不同调用。 |
| Metric3D | 候选插入记录原预测深度的有限正值比例与分位数（p05、P50、P90、P95），保留 Metric3D 推理与先验存储行为；原生产物中的 keyframe mono_disps 与 BA 后的深度保留，不为消融改动 save_depth。对非 pose-only 的 BA 单列缓存正掩码比例和实际参与掩码比例。分母取 native kx=unique([t0,t1) ∪ 源端图槽) 的全部低分辨率像素。缓存掩码沿用 native >0，作为原生支持而非传感器真值；原预测有限性另外审计。D=0 时缓存仍可用，但参与计数为 0。 |
| U / UBA | U 的有限比例、median/P90/P95、源端乘子和有效 x/y 权重分位数、有效投影样本数、有效投影中双通道同为零及非法权重的样本数；分开列投影资格与正权重。原生权重采用 CUDA 几何深度门，候选用 CPU 复算同一边界状态并加有限性检查，最多 24 条边、每轴步长 4，保留采样索引和分母。不是 CUDA 内部实际累积权重或 Hessian 的完整读取。 |
| 视差 | 原生返回紧接上层 clamp 前，再在 clamp 返回后记录。对当时全部有效前缀槽位及 Filler 临时槽的低分辨率网格，记录 n、有限负值数、nonfinite、恰等于 float32(1e-5) 的数量；相同 ba_id 两个口径的 n 必须一致。抽样视差和深度分位数另列采样 n。整批缓存的未用预留槽位不算入；不将 floor 等同于负值数量。 |
| Final BA / Filler / 导出 | 前端结束、前后两阶段与每次外层返回，按批插值、优化、批结果和重插原生关键帧后导出；分别记录原生和临时位姿、插值锚点、frame/slot/batch 对应。 |
| 运行与资源 | 干净退出码、完整模型 stdout/stderr、阶段进度、GPU 设备级采样峰值、torch 进程分配/保留峰值、cgroup RAM、shm、磁盘、Rerun 进程及浏览器接收和渲染证据。记录采集/摘要、复制及序列化/写入耗时。复制耗时包含在采集计时口径，不重复相加。 |

## 不可替代的现场检查（未来，当前未执行）

- 每次都先核对 manifest/RGB/K、环境、固定扩展、源快照及两个补丁的确切后像。启动收据绑定 commit、配置、策略、attempt 和 Rerun 版本，和 final-phase/visualizer 权限完全对应。
- 按 schema 严格解析日志：按进程验证 event 序、BA 各边界配对、无越界槽、输入读取与导出覆盖。核对各类不变阶段和主循环实参。在 E1/E4/E6/E8 核对 D 关且有缓存支持时，实际 depth prior 选择为 false；W=0 源端乘子为 1；U=0 未调用更新分支。U 在相邻调用间变动可能来自插入/转移，不用跨调用数值不变替代位审计。
- 三个 Rerun 端口（历史远端 9875/9876/9877）先验证监听、转发和真实浏览器渲染合成探针。记录当前访问地址、TCP/WebSocket 和渲染证据。正式运行保留原生 Rerun，观察真实点云/相机实体；看不到内容时先保留诊断，不静默关闭后继续。
- 原生 BA 返回可能已经完成多个 inner iterations。本候选未截获内层每次 retraction、完整 Jacobian 或 Schur 矩阵。完整活动网格统计也无法看见在原生中间迭代出现又消失的负值。
- 观测文件上限 384 MiB/次，越限抛出并保留前缀；日志缺尾判定不完整。不得裁掉诊断日志继续消融，或绕开止损重跑。更改采样须按新的观测版本审批。

历史 Task003 生成 5,353 条可解析事件；累计采集与摘要约 17.38 s（其中约 3.31 s 读回）、编码写入约 4.78 s。此处为已有运行的观察计时，不能当作当前新增统计的预计开销或 GPU 时间。详见 [源证据](evidence/HISTORICAL_INPUTS.json) 和 [资源预算](TASK004_RESOURCE_AND_RUN_BUDGET.md)。
