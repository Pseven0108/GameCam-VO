# Confidence 与 GT 深度误差审计

**状态：真实误差统计未获数据准入，未执行。**

本轮只检查实际缓存的身份、字段、尺寸、有限性、Confidence分位数及取值范围。
所有分位数均为原生分数，不是正确概率、方差或GT误差；没有因预测看起来不好而删点。
逐帧数据：`data_audit/VIPER_CONFIDENCE_CACHE_INTEGRITY.csv`。

| Night | val_007 | 00001、00244 | 196 | 0 |
| Snow | val_021 | 00001、00355 | 11,326 | 0 |

每环境460,800个预测网格像素。没有GT时，这些像素数不能叫GT有效像素，也不能说明哪种环境更准确。
16个归档的中央目录仅表明当前本地产品的成员类型，不是整个官方VIPER数据产品审查，更不是所有payload的CRC检验。
44个额外二进制候选的头部与NPZ字段均单独记录；未核实的归档片段保持未核实。

本轮没有使用相机位姿、优化后深度、光流u/v、模型自身深度、TTA有效区域或MVS-Synth充当VIPER GT。
因此不报告误差相关性、AUROC、误差分箱、NLL、覆盖率、环境校准曲线、像素级显著性或深度准确性改进。

MVS-Synth的单位限制来自实际读取的R2.2 `GT_QUALITY_SUMMARY.json`、`PROTOCOL.json`、`R2_2_DECISION.json`，其文件哈希记录在本包。
没有重用历史scale做本轮米制认证，也没有把已观察0001改称新鲜独立测试。
