# 解除本轮阻断所需的最小证据

本轮已经依照用户的停止条件结束，不申请新数据下载或重新推理。

恢复VIPER校准前，需明确提供或授权取得：

1. 精确匹配目标sequence/RGB ID的真实像素深度GT；相机CSV、光流和SLAM估计深度不能代替。
2. 原始发布来源、发行版本、文件身份及使用范围；深度是Z-depth、range或inverse depth的定义。
3. 共同单位或可审查的固定转换、远平面/无穷/零值定义，以及官方有效性和遮挡处理。
4. RGB、GT、K、预测depth和Confidence的完整空间变换；明确1920×1080与640×360对应，不能默认同名文件自动像素对齐。
5. 无测试拟合的序列级Calibration/Evaluation划分；当前10帧来自已经观察的Validation。

若选择其他带GT的数据集，应另行明确数据集范围和独立划分；MVS-Synth不是VIPER，不能无声替换。
本轮不重新使用历史拟合scale，不新抓取VIPER全量数据，也不开发Scalix式网络。
