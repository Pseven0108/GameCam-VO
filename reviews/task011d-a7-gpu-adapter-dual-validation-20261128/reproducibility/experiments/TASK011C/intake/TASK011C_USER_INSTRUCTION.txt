# 一、研究目标

TASK011B 已经发现，A5（Validity-Aware Max Fusion）在当前 VIPER 实验中取得了最好的平均 Sim3 ATE/path 表现。

但目前尚未证明其收益来自像素级空间可靠性控制。

需要排除另一种解释：

A5 只是整体降低了深度先验的作用强度，因此即使不进行像素级可靠性判断，也可能获得类似收益。

本任务通过增加 A7 Uniform Attenuation Control，验证：

**在保持相同 Native-valid 有效像素掩码、相同平均深度先验强度的条件下，A5 的空间差异化可靠性分配是否仍然优于 A7 的均匀可靠性分配。**

本阶段不追求增加模块数量，而是验证现有模块是否具有独立的研究价值。

# 二、研究假设

H1：A5 优于 A7，说明像素级空间可靠性分配具有独立价值。

H2：A5 与 A7 表现接近，说明当前性能收益可能主要来自整体减弱深度先验。

H3：A5 优于 A0，但不优于 A7，不能将收益归因于空间可靠性选择。

H4：A5 在不同随机种子和不同天气环境下保持相对稳定，才能支持进一步发展为 DROID-W 的正式改进模块。

## A7 核心设计

严格复用 A5 的原始可靠性计算结果。

A5 的可靠性定义：

- 在 Native-valid 与 TTA pair-valid 的共同有效域内，使用 Native confidence risk 和 Flip disagreement risk 的最大值。
- 对 TTA pair-invalid 区域，保留 Native-only fallback。
- 不改变原始无效深度拒绝规则。

A7 不重新计算另一套置信度，也不使用新的模型。

对于每个实际参与 BA 的源帧，定义：

M(x)：原始 Native prior mask 与 Native-valid mask 的交集。

r5(x)：A5 的像素级可靠性系数。

计算：

`r7_mean = mean(r5(x) for x in M)`

然后：

- M 内所有有效像素使用相同的 `r7_mean`。
- M 外全部设置为零。
- 保留 A5 原始有效像素支持集。
- 保留原始深度先验 alpha=0.01。
- 保留原始 BA 目标、迭代次数、U 更新、Schur 求解和重投影流程。

数学定义：

[\
\bar r_t =\
\frac{\sum_x M_t(x)r\_{A5,t}(x)}\
{\sum_x M_t(x)}\
]

[\
r\_{A7,t}(x)=M_t(x)\bar r_t\
]

重要：

均值必须基于实际 BA 调用使用的 source indices 和 prior mask 计算，不能简单对整张 640×360 图像求平均。

如果不同 BA 调用的有效源帧或 mask 不同，必须按实际调用动态计算。

A5 与 A7 必须满足：

1. 有效支持集完全一致。
2. 每帧有效区域的平均可靠性系数一致。
3. 每次 BA 调用的平均有效先验系数一致。
4. A7 有效区域内部的可靠性系数为常数。
5. A7 不增加额外模型推理。

均值一致性建议容差：FP32 下绝对误差不超过 1e-6；如果原生运算精度导致无法满足，必须先解释并通过单元测试确定合理容差，不得静默放宽。

# 八、评价指标

## 主指标

Sim3 ATE/path (%)。

核心对照：

`A5 vs A7`

定义：

[\
\Delta = Metric(A5)-Metric(A7)\
]

负值代表 A5 更好。

## 次指标

1. Sim3 ATE RMSE。
2. SE3 ATE/path。
3. RPE Translation。
4. RPE Rotation。
5. Raw Path Ratio Absolute Error。
6. 完整轨迹成功率。
7. 初始化失败率。
8. Tracking Runtime。
9. Peak GPU Memory。

不能仅使用 Sim3 ATE 判断算法是否改善。

特别注意：Sim3 ATE 不能作为真实 Metric Scale 得到改善的证明。

## 统计方法

- 以源序列为统计聚类单位。
- 同一源序列内三个随机种子作为重复测量。
- 使用配对比较。
- 采用10,000次 sequence-level cluster bootstrap。
- 输出95%置信区间。
- 输出每个实验组的成功率、失败率、均值、中位数、标准差。
- 不将失败轨迹的误差伪造为零。
- 分开报告完整轨迹与 ATE 可评分轨迹。
- 不将同一序列的三个 seed 当作三个独立数据样本。

主要确认性比较仅为 A5 对 A7。

其他比较作为次要分析。

# 九、预先登记的判定标准

### 情况 A：A5 显著优于 A7

要求：

- A5-A7 的配对 ATE/path 差值小于零。
- 95% cluster bootstrap 区间上界小于零。
- A5 的轨迹完成率没有超过5个百分点的明显劣势。
- Raw Path Ratio、RPE 和运行成本没有出现不可接受的退化。

结论：

支持空间差异化可靠性控制具有独立价值。

可以进入后续模块优化和更大规模验证。

### 情况 B：A5 与 A7 接近

要求报告：

- 两者均值差。
- 95%置信区间。
- 两者空间可靠性分布。
- 两者实际平均先验强度。

结论：

目前没有充分证据证明空间差异化控制优于均匀衰减。

需要考虑简化模块，而不是继续增加复杂度。

### 情况 C：A7 优于 A5

结论：

当前 MaxFusion 的空间分配策略可能存在误判，或者像素级可靠性排序并未转化为有效的 BA 优化收益。

暂停 A5 的生产化。

### 情况 D：A5 只优于 A0，不优于 A7

结论：

收益更可能来自整体深度先验衰减，而不是已经证实的空间可靠性选择价值。

不得宣称已经证明像素级可靠性控制有效。

置信区间跨越零时，结论为证据不足，而不是证明两者等价。
